# Explore 716 website

Static landing page and privacy policy for the Explore 716 Android app.

- Home: `index.html`
- Privacy policy: `privacy/index.html`
- Styling: `styles.css`
- Branding: `assets/explore716-icon.png`, copied from the approved mobile app artwork

Host the repository from the `main` branch and root folder in GitHub Pages. No build step, analytics script, or external runtime dependency is required.

Expected URLs:

- https://savicreations.github.io/explore716-site/
- https://savicreations.github.io/explore716-site/privacy/
